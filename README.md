# DASH.L.I.H

Dashboard operativo interactivo del **Laboratorio de Investigación Hormonal (L.I.H)**.

- Datos en vivo desde Google Sheets (actualización automática cada 5 min).
- Pestañas: Volumen, Per Cápita, Tiempos.
- Filtros por año, mes y día. Diseño ejecutivo con la identidad de marca L.I.H.

**Publicado en GitHub Pages.**
